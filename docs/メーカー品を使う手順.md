# メーカー品の建具・便器を使う手順（AI への指示書）

この文書は、このツールを受け取った人の AI（Claude など）が読むためのものです。
最初の状態では、建具（窓・ドア・玄関ドア）と便器は **汎用の形（メーカーなし）** で描きます。
決まったメーカーの部品で描きたい時は、以下の順に進めてください。

---

## 0. 守ること

- **メーカーの CAD データは、利用者が自分でメーカーのサイトから取ってくる。** AI が勝手に取ったり、ほかの人に配ったりしない。データを使ってよいか（利用条件）は、利用者に確かめてもらう。
- メーカーの CAD データ（.jww / .dxf）と、それから作った部品集は、**このリポジトリ（公開版）に入れない・コミットしない**。利用者の PC の中だけに置く。
- 仕様ファイル（`05_設定/仕様/*.json`）に会社名・お客様名を書いた時も、公開しない。
- 迷ったら作業を止めて、利用者に聞く。

---

## 1. 仕組み（読む順）

| ファイル | 役目 |
|---|---|
| `05_設定/default.json` | 基準の設定。壁の各面の位置、部品集の場所など |
| `05_設定/仕様/<名前>.json` | 仕様ファイル。`"_extends": "../default.json"` で基準を引き継ぎ、**違う項目だけ**を書く（辞書は中身どうしを重ね、リストと数値は丸ごと置き換える。`scripts/spec.py`） |
| `05_設定/現在の仕様.txt` | 今使う仕様の名前（1行）。`run_all.ps1` は作図（make_plan）にこの仕様を使う |
| `scripts/custom_spec.py` | 壁の厚みの数字から仕様ファイルを作る。汎用の建具の部品集もここで作る |
| `scripts/place_fittings.py` | 部品集を読み、検出した開口に部品を置く |
| `scripts/check_conditions.py` | できた図面を検査する（NG が 0 になるまで直す） |

壁の厚みだけを決めた仕様は、次のように作ります（単位 mm）。

```bash
py -3.13 -I scripts/custom_spec.py うちの標準 16 18 60 9.5 105 12.5
```

数字の並びは、外壁材・通気層・付加断熱・構造用面材・柱・室内の石膏ボードです。
これで `05_設定/仕様/うちの標準.json` と、汎用の部品集 `05_設定/仕様/うちの標準_部品/` ができます。

---

## 2. メーカーの部品集を作る

部品集は、**ブロック（部品）を並べた .jww ファイル**と、その横に置く **一覧 CSV** です。
汎用の部品集（`custom_spec.build_generic`）が見本になるので、まずそれを作って中身を見てください。

### 2.1 ブロックの名前

```
<メーカー>_<シリーズ>_<種類>_W<幅>
```

- 例：`メーカーA_シリーズB_片開き_W780`
- 種類は、次のどれかと同じ文字にする（`place_fittings.WORDS`）：
  `片開き` `片引戸` `アウトセット片引戸` `引違い戸` `両開き` `折戸` `UBドア` `引違い窓` `縦すべり窓` `FIX窓` `横すべり窓` `縦すべり+FIX窓` `玄関片開き` `玄関親子`
- 幅は、枠の外から外までの mm（整数）。
- 同じ種類で幅違いをいくつか入れておくと、開口にいちばん近い幅が選ばれる。

### 2.2 ブロックの形の決まり

ブロックは **縮尺 1/50 の紙の mm** で描きます（図面上の mm ＝ 実寸 mm ÷ 50）。

- **基準点（0,0）＝左の柱の中心**で、壁の芯線の上にある。
- **x ＝壁に沿う向き**（右が +）、**y ＝壁を横切る向き**。
- 窓・玄関ドアは、**+y が外**。
- ドア（室内）は、**+y に開く**。吊り元は左。
- 片引戸は、右半分が戸袋。**中方立は x ＝枠の左端 + 幅/2**。
- アウトセット片引戸（壁を削らずに壁の表面に付ける引戸）は、戸が −y の面を右へ走る。開口の両脇の枠は、+y 側へ長さ100以上の縦の線で描く（その外から外が開口になり、壁を切るのも柱をよけるのもそこだけ）。
- 縦すべり窓は、右端に軸がある。
- 線は、レイヤ 3、線色 1、実線。線色 5（紫）と線色 6（青）は使わない。紫は壁の石膏ボード、青は検査で「消し忘れ」と判定される。

枠の位置（柱芯から、実寸 mm）：

| 種類 | 枠の左端（柱芯から） | 壁を横切る向き（y） |
|---|---|---|
| 室内ドア | 65（柱の面 52.5 ＋ 12.5）。910 の柱間にちょうど入る幅なら、柱間の真ん中 | 枠の厚み 155（芯から ±77.5） |
| 収納の折戸・両開き | 同上 | 開かない側の枠の面を、室内の石膏ボード面にそろえる（−y の端 ≧ −ボード面） |
| 窓 | 柱間（455 の倍数で、幅＋105 が入る最小）の真ん中 | **枠の厚み 130 の真ん中が、付加断熱の外面**（仕様の `offsets_mm.exterior_side.added_insulation`） |
| 玄関ドア | 65 | 窓と同じ考え。扉の幅は、枠の内側（左右の耳）の間 |

- 柱芯から枠の左端までの寸法は、一覧 CSV の「柱芯から枠外まで」に書く。なければ `place_fittings.std_offset` の値になる。
- 窓は、付加断熱の厚みで位置が変わる。付加断熱の違う仕様ごとに、部品集を作り直す（汎用の部品集は、仕様を作る時に自動で作り直している）。
- ドアの開く円弧の両端は、扉の線か枠の線に接するように描く（検査 E）。

### 2.3 一覧 CSV

部品集の .jww と同じフォルダに `建具部品集_一覧.csv`（UTF-8 BOM 付き）を置きます。

```
ファイル,ブロック名,メーカー,シリーズ,種類,幅W,柱芯から枠外まで,柱芯々,備考,元データ,元データ取得日,元データ公開日,商品ページ
```

使うのは「ブロック名」と「柱芯から枠外まで」です。
ほかの列は、あとで元データをたどるための記録です。取得日・商品ページも書いておいてください。

### 2.4 メーカーの図からブロックを作る手順

1. 利用者に、メーカーのサイトから**平面図**の CAD データ（.jww か .dxf）を取ってきてもらう。
2. 部品の平面の線だけを取り出す。寸法・文字・基準線・塗りは入れない。
3. 実寸の向きを 2.2 にそろえる（回す・裏返す）。
4. 基準点を、左の柱の中心に移す。
5. 1/50 の紙の mm にする。
6. ezjww（Jw_cad のファイルを読み書きする Python ライブラリ）の `new()` → `add_block(名前, 図形のリスト)` → `saveas()` で書き出す。
   図形の辞書の形は、`custom_spec.build_generic` と同じにする。
7. 一覧 CSV を書く。

## 3. 部品集を仕様で使う

仕様ファイルの `placement.library` に、部品集の .jww のパスを**リスト**で書きます。
パスは、リポジトリの一番上からの相対です。複数書いてよく、全部をまとめて使います。

```json
{
  "_extends": "うちの標準.json",
  "placement": {
    "library": [
      "03_建具部品/メーカーA/部品集_窓.jww",
      "03_建具部品/メーカーB/部品集_室内ドア.jww",
      "05_設定/仕様/うちの標準_部品/部品集_汎用.jww"
    ]
  }
}
```

- 同じ種類の部品が複数の部品集にある時は、開口に近い幅が選ばれる。メーカーを混ぜたくない時は、使わない部品集を外す。
- `custom_spec.make_spec(名前, ..., parts=[".jww のパス", ...])` でも書ける。

### 便器

便器は `toilet_part` に、部品の json のパス（リポジトリの一番上から）を書きます。
`"generic"` なら汎用の形です。

```json
{"toilet_part": "03_建具部品/メーカーC/便器/便器.json"}
```

json の形（実寸 mm、**便器の中心が原点、前（とがった側）が +x**）：

```json
{"長さ_mm": 736, "幅_mm": 386,
 "entities": [
   {"t": "L", "p": [x1, y1, x2, y2]},
   {"t": "A", "c": [cx, cy], "r": 半径, "a0": 始まりの角度（ラジアン）, "sw": 開き角（ラジアン）},
   {"t": "C", "c": [cx, cy], "r": 半径}
 ]}
```

## 4. 確かめる

1. `05_設定/現在の仕様.txt` に仕様の名前を書いて、`run_all.ps1` で作図する。
2. 検査を通す。

   ```bash
   py -3.13 -I scripts/check_conditions.py <図.jww> <_meta.json>
   ```

   全部の図面をまとめて見る時は、`--all` を付ける。
   `check_conditions.py` の部品のメーカーの確かめ（検査 K）は、知っている名前の頭だけを通します。
   新しいメーカーの部品を使う時は、K の行に、そのブロック名の頭を足してください。
3. NG が出たら、部品の形（2.2）を直して、部品集を作り直す。
   紫線のはみ出しや欠けた部品の線は、`scripts/fix_fittings.py` が直せる分を直します。
4. 図を画像にして、利用者に見てもらう。窓・ドアの位置や向きがおかしい所は、利用者に聞く。
