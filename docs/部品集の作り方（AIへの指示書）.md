# 部品集の作り方（AI への指示書）

この文書は、このツールを受け取った人の AI（Claude など）が読むためのものです。
利用者から「メーカーの部品で図面を描きたい」「部品集を作って」と頼まれたら、この順に進めてください。

このツールは、建具（窓・ドア・玄関ドア）と住設（キッチン・洗面台・浴室・便器）を、**部品集**（部品のデータ）から配置します。
**部品集は、このリポジトリに入っていません**（メーカーの CAD データの利用条件で、再配布できないため）。
部品集にない部品は、**汎用の形（メーカーなし）で描きます**。部品集がなくても、ツールは最後まで動きます。
メーカーの部品で描きたい時だけ、利用者の手元で部品集を作ります。

---

## 0. 守ること

1. **メーカーの CAD データは、利用者が自分でメーカーのサイトから取ってくる。** AI が勝手に取らない。取る前に、各社の利用条件を利用者に見てもらい、同意を得る。
2. **メーカーの CAD データ（.jww・.dxf・.zip）と、それから作った部品集（.jww・.csv・parts_spec.json など）は、リポジトリにコミットしない・公開しない・他人に渡さない。**
   置き場所は `03_建具部品/`（`.gitignore` に入っている。コミットする前に `git status` で、部品集や CAD データが入っていないか確認する）。
3. 建築の設計・設計検討に使う範囲で使う。複製品の製作など、利用条件が禁じることはしない。
4. 部品の寸法・形は、メーカーの図面が正。作ったあと、必ず図面に置いて確かめる（7 章）。
5. 迷ったら作業を止めて、利用者に聞く。

## 2. 作る手順

### 2.1 フォルダを決める

メーカーごとに、次のようなフォルダを作ります（`03_建具部品/` の下）。

```
03_建具部品/
  YKK_APW430/
    元データ/          ← メーカーから取った .jww
    ready/             ← build スクリプトが作る「できあがり部品」
    parts_spec.json    ← 同上
    部品集/            ← 最後にできる 部品集_窓.jww と 建具部品集_一覧.csv
  パナソニック_ベリティス/（zip・DXF のフォルダ・ready・部品集）
  パナソニック_水廻り/（キッチン_dxf・バスルーム_dxf・洗面_dxf・部品集）
  TOTO/（キッチン_dxf・トイレ_jww・便器_GG）
  元データ一覧.csv     ← 取ったデータの記録（2.4）
```

メーカーの zip は、`zip/` に原本のまま置き、展開した中身を別のフォルダに置きます。

### 2.2 スクリプトで作る（作り方はスクリプトごとに違う）

どのスクリプトも、先頭の説明文に、入力・出力・決まりが書いてあります。**実行する前に、必ずその説明文を読んでください。**
Python は 3.13 を使い、`py -3.13 -I scripts/<スクリプト名>` の形で実行します。

**窓（YKK AP APW430）**

1. 意匠図・建具表の .jww を `03_建具部品/YKK_APW430/元データ/` に置く。
2. `py -3.13 -I scripts/build_ykk_windows.py` → `ready/` と `parts_spec.json` ができる。
3. `py -3.13 -I scripts/build_parts_library.py 03_建具部品/YKK_APW430 05_設定/default.json 03_建具部品/YKK_APW430/部品集` → `部品集_窓.jww` と一覧 CSV ができる。

**玄関ドア（YKK AP イノベスト）**

1. `03_建具部品/YKK_イノベスト/元データ/` に INBD50_*.jww を置く。
2. `py -3.13 -I scripts/build_ykk_parts.py`
3. `build_parts_library.py` を、窓と同じ形で実行する（フォルダを `YKK_イノベスト` にする）。

**室内ドア（パナソニック ベリティス）**

1. 内装ドアの一括ダウンロード（DXF）を展開して、`03_建具部品/パナソニック_ベリティス/スタンダード2026_dxf/` に置く（品番表の `indoor60.csv` も）。収納用建具も使う時は、収納用建具の DXF も取る。
2. `py -3.13 -I scripts/build_panasonic_parts.py 03_建具部品/パナソニック_ベリティス`
3. `build_parts_library.py 03_建具部品/パナソニック_ベリティス 05_設定/default.json 03_建具部品/パナソニック_ベリティス/部品集`

**住設（パナソニック・TOTO のキッチン、パナソニックの洗面台・浴室）**

1. パナソニックの水廻り設備（キッチン・バスルーム・洗面）の DXF と、TOTO のキッチン DXF を、`03_建具部品/パナソニック_水廻り/` と `03_建具部品/TOTO/` の下に展開する。
2. `py -3.13 -I scripts/build_waterworks_parts.py 03_建具部品/パナソニック_水廻り 03_建具部品/パナソニック_水廻り/部品集`
3. `水廻り部品集.jww` と `水廻り部品集_一覧.csv` ができる。どの型番を部品にするかは、スクリプトの `PARTS` の表にある。商品を増やす時は、この表に 1 行足す。

**便器（TOTO GG）**

1. TOTO のトイレの jww（2_JWW.ZIP）を展開して、`03_建具部品/TOTO/トイレ_jww/` に置く。
2. `py -3.13 -I scripts/build_toilet_part.py` → `03_建具部品/TOTO/便器_GG/便器_GG.json` ができる。

**LIXIL（窓 EW・室内ドア ラシッサ・玄関ドア ジエスタ2）**

LIXIL の .jww は、1 枚に平面の部品が何個も描いてあります。部品を取り出すスクリプトを、次の順に使います。

1. `py -3.13 -I scripts/cluster_parts.py <シート.jww>` ：平面の部品（横長のまとまり）と、近くの「W=」の文字を一覧にする。
2. `py -3.13 -I scripts/crop_part.py <シート.jww> x0 y0 x1 y1 <出力.png>` ：範囲を画像にして目で確かめる。
3. `py -3.13 -I scripts/add_parts_from_sheet.py <フォルダ> <シート.jww> <y0> <y1> <メーカー> <シリーズ> <種類> <op> <備考>` ：`parts_spec.json` に部品を足す。
4. `build_parts_library.py` で部品集にする。

### 2.3 部品の名前と形の決まり（とても大事）

画面の「水廻り」の欄や、建具の自動選択は、**部品（ブロック）の名前**から作ります。名前の決まりを守ってください。

- 建具：`<メーカー>_<シリーズ>_<種類>_W<幅>`（例：`LIXIL_ラシッサ_片開き_W778`）
- キッチン・洗面台：`<メーカー>_<キッチン／洗面>_<商品>_W<幅>`、必要なら最後に付記（例：`パナソニック_キッチン_LVI25IA_W2550_IH`、`パナソニック_洗面_CLine_W900`）。フラット対面は付記を `ペニンシュラ` にする。
- 浴室：`<メーカー>_UB_<大きさ4桁>_<ドアの位置>_<向き>`（例：`パナソニック_UB_1616_ドア下_シャワー鏡が正面`、`…_ドア右_浴槽が正面`）。
- 種類の文字は `scripts/place_fittings.py` の `WORDS` と同じにする。
- 形の決まり（基準点・向き・縮尺 1/50・線の色など）は、`docs/メーカー品を使う手順.md` の 2.2 を読む。

### 2.4 元データの記録

取ったデータは、`03_建具部品/元データ一覧.csv` に、メーカー・商品・入手先 URL・取得日・ファイルの大きさ・MD5 を記録します。
`scripts/check_parts_updates.py` が、記録と更新の確認をします（LIXIL のサイトの分）。メーカーが新しい版を出していても、**自動では取らず**、利用者に聞きます。

## 3. 仕様に部品集をつなぐ

### 3.1 建具

仕様ファイルの `placement.library` に、部品集の .jww のパスを書きます（リポジトリの一番上からの相対パス。複数書いてよい）。

```json
{
  "_extends": "../default.json",
  "placement": {
    "library": [
      "03_建具部品/YKK_APW430/部品集/部品集_窓.jww",
      "03_建具部品/YKK_イノベスト/部品集/部品集_玄関ドア.jww",
      "03_建具部品/パナソニック_ベリティス/部品集/部品集_室内ドア.jww"
    ]
  }
}
```

同じ種類の部品が複数の部品集にある時は、開口に近い幅が選ばれます。メーカーを混ぜたくない時は、使わない部品集を外します。

### 3.2 住設（キッチン・洗面台・浴室・便器）

**画面の「カスタム」の欄の「水廻り」で選ぶのが簡単です。** 部品集のブロック名から、メーカー → 商品 → サイズの一覧が自動で出ます。選んだ内容は、仕様ファイルの `kitchen_part`・`vanity_part`・`ub_part`・`toilet_part` に書かれます。
手で書く時は、`scripts/custom_spec.py` の `wet_spec` を見てください（書き方が決まっています）。

### 3.3 部品集にない部品

部品集にない部品は、**汎用の形で描きます**（建具は `custom_spec.build_generic` の汎用の部品集、便器は汎用の形、キッチン・洗面台・浴室は簡単な外形）。
利用者に「ここは汎用の形になっている」と、はっきり伝えてください。

## 4. 確かめる

1. 部品集の中身：`py -3.13 -I scripts/inspect_part.py <部品集.jww> <出力.png>` で、ブロックの数・名前と、見た目（PNG）を確かめる。名前が 2.3 の決まりに合っているか見る。
2. 図面に置く：1 つのプランで作図して、部品が置かれ、向き・位置が合っているか、画像で見る。
3. 検査：作図でできた `<階>.jww` と `<階>_meta.json` に、`py -3.13 -I scripts/check_conditions.py <図.jww> <_meta.json> [検査画像.png]` をかける。結果が NG 0 になるまで直す。
4. 利用者に、できた図の画像を見せる。
