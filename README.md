# プラン図から Jw_cad 平面詳細図を自動作図

プレゼン用のプラン図（PDF、1/100、図面部分は画像）から、Jw_cad の平面詳細図（1/50、.jww）の「とっかかり」を自動で作図する Python のコードです。100%の完成図ではなく、壁のオフセット・柱・建具の配置までを自動で描き、最後は人が手を入れる前提です。

Claude（Anthropic の AI）と対話しながら作ったものです。

> **ウォークインホーム（3D CAD ソフト）専用です。**
> ウォークインホームで作ったプレゼンボードを PDF に出力したもの（壁は灰色の塗り、文字・寸法は画像のまま）を前提にしています。他の CAD ソフトや手描きの図面には、そのままでは使えません。
> ただし、壁の色・線の太さ・縮尺などの数値を合わせれば、他の 3D CAD のプラン図にも対応させられる可能性が高いです（下の「数値はご自身の環境に合わせて直してください」を参照）。

## 使い方（AI 任せ・おすすめ）
プログラミングが分からなくても使えるように、**AI に読ませる前提**で作っています。
1. このリポジトリを丸ごとダウンロードする（緑の「Code」ボタン →「Download ZIP」→ 展開）
2. 展開したフォルダで Claude Code などのコーディング AI を開き、こう頼む：
   **「README.md と CLAUDE.md を読んで、セットアップして動かして」**
3. AI の案内に従って、必要なもの（Python、建具の部品集、入力の PDF）を用意する
4. 出てきた図面と確認画像を AI と一緒にチェックし、自分の会社の基準に合わせて数値を直してもらう

`CLAUDE.md` は AI 向けの説明書です（Claude Code はフォルダを開くと自動で読みます）。この README を読まなくても、必要なこと（用意するもの、やってもらうと精度が上がること）は AI の方から話しかけて伝えるようにしてあります。

## できること
- 図面画像から壁を判定（910 → 455 → 227.5 のグリッドを順に読み、最後に寸法の数字を読んでグリッド外の通りを確定）
- 外壁・内壁の判別、壁芯から各層（柱面・石膏ボード面・面材・付加断熱・通気層・外壁面）のオフセット線
- 柱（105角）の配置：端部・L字・T字・十字、残りは1820刻み
- 開口部の判定と建具部品の配置（片開き・引戸・折戸・両開き・窓の種類と幅）
- 確認用に、検出結果を元の図面に重ねた画像を出力

## 必要なもの
- Windows（部屋名・窓の記号の読み取りに Windows の文字読み取り機能を使います）
- Python 3.13
- `pip install -r requirements.txt`
- 建具の部品集（.jww）：メーカーの CAD データから各自で用意してください（このリポジトリには入っていません）。置き場所は `03_建具部品\`、一覧は `scripts\build_parts_library.py` を参照

## 使い方
```
.\run_all.ps1 -Pdf 01_入力\プラン.pdf -Name プラン名 -Img1F <1Fの画像名> -Img2F <2Fの画像名>
```
- 入力の PDF は `01_入力\` に置きます。図面の画像名は `scripts\extract_plans.py` の表示で確かめます
- 出力は `02_出力\プラン名\`（1F.jww・2F.jww と確認画像）
- 作図の決まり（オフセット寸法・レイヤ・線色・線種・柱寸法など）は `05_設定\default.json` で変えられます

## 数値はご自身の環境に合わせて直してください
このスクリプトの数値は、作者の会社・作図の決まりと、ウォークインホームの図面の描き方に合わせたものです。そのまま使える保証はありません。「暫定」と書いてある数値は、特に仮の値です。例：

**入力図の読み取り（判定の土台）**
- 縮尺：1px あたりの mm（初期値 12.5、探す範囲 12.0〜13.0）
- グリッド：455（半グリッド 227.5）、グリッドから外れた壁を許すか
- 図面画像の取り出し（PDF のどの画像が平面図か）

**壁の判定**
- 壁の灰色の範囲（RGB の明るさ 180〜197、自動推定の幅 ±8、色味のずれの許容 10）
- 壁の帯の太さ（6〜22px）、外壁とみなす太さ（13px 以上）
- 壁の輪郭線とみなす黒の濃さ、帯の中心のずれの許容（3px、外壁 5px）
- 途切れをつなぐ長さ（外壁 300px・内壁 90px）、短すぎる線を捨てる長さ（20px）
- 壁の判定の段階（910 → 455 → 227.5）、壁・建具とみなす割合、内壁の最短長さ（455mm）

**寸法の読み取り**
- 寸法線とみなす線の濃さ・長さ（150px 以上）、引出線の長さ（12px 以上）・本数（3本以上）
- 寸法の数字の読み取り（OCR）と、引出線の間隔との照合の許容

**文字の消し込み**
- 赤字（寸法・建具記号）とみなす色の差（RGB 差 60 以上）、文字の大きさ（28px まで）

**開口部・建具の判定**
- 建具を探す帯の幅（±12px）、開口とみなす最小の隙間（4px）
- 開き戸の円弧・引戸の引込み・両開き・折戸の見分けの基準（円弧らしさ 0.7 以上 など）
- 窓の種類の見分け（扇の形・点線の長さと間隔・FIX との境目の割合）
- 窓の記号の読み方（16020H・06011T などの幅の対応表）
- 収納の扉・UB ドア・トイレの便器の形の判定の大きさ

**腰壁・家具・外部空間**
- 腰壁（塗りのない帯）の太さ（片側 3〜6px）と最短長さ（800mm）、笠木の芯振り（75）
- 家具・カウンター・階段の線を壁から外す条件
- 外部空間とみなす部屋名（ガレージ・ポーチ・バルコニー）

**作図**
- 壁芯からの各層の距離（柱面 52.5・石膏ボード面 65・面材 61.5・付加断熱 121.5・通気層 139.5・外壁面 154.5）
- 柱の寸法（105角）、柱の刻み（1820）と余りのまとめ方
- 建具の納まり（枠の位置 65、収納の枠の出 12.5、入隅の窓の離れ 50、玄関の額縁の厚み 21〈暫定〉、上がり框 52.5・157.5〈暫定〉）
- 建具の部品の選び方（引戸 W1644／W1454 の決め方、小さい戸の扱い）
- レイヤ・線色・線種、縮尺（1/50）、図面枠と印刷位置合わせ印の位置（A3 で ±205・±144 など）

多くは `05_設定\default.json` にまとめてありますが、コードの中に直接書いてある数値もあります。**Claude Code などのコーディング AI に「自分の会社の基準に合わせて」と頼んで、スクリプトに手を加えて使ってください。** 自分で手直しした正解図面（.jww）を渡して、自動の出力と比べさせると、違いから合わせ込んでくれます。

## 最初に持っておく考え方：いきなり丸投げで全部覚えさせるのは無理
AI に「この図面を全部描けるようになって」と丸投げしても、うまくいきません。**このマインドで始めてください。**
- **複雑な納まりや、ルール化しづらい作図は、AI に覚えさせず、人がやると割り切る**
- AI が得意なのは、決まった規則でくり返す作業（壁のオフセット、柱の配置、建具の部品を置く など）。そこを任せる
- 例外が多いもの・その場の判断が要るもの（複雑な取り合い、吹抜・階段まわり、特殊な建具の納まり など）まで覚えさせようとすると、時間がかかるうえに、他の図面で余計な線を描いて手直しが増えます
- **余計なものを描かれるくらいなら、描かれない方が手間が少ない**。AI には「迷う所は描かずに残す」くらいでちょうどよいです
- 人と AI で分担して、AI に任せる範囲は「これは毎回同じだ」と分かったものから少しずつ広げます

## 人がやった方がいいこと（AI の改善に効いたこと）
このスクリプトは、作者が AI に次のように手を貸して育てました。自分の環境に合わせる時も、これをやると早く良くなります。

1. **正解の図面を1枚、自分で描いて渡す**
   自動の出力と正解を AI に比べさせると、点数（どれだけ合っているか）で良くなったか悪くなったかを AI が自分で判断して、試行錯誤を続けられます。
2. **自動の出力を Jw_cad で手直しして渡す**
   線1本ずつの違いから AI が規則を見つけて、次から同じ所を自動で直せるようになります（建具の両脇の納まり、収納の枠の出など）。
3. **判定の「考え方」を言葉で教える**
   AI は全部の線を一度に読もうとして、家具や設備まで壁と間違えます。実務の知識で順番や前提を教えると一気に良くなります。例：
   - 木造軸組はモジュールから外れない。まず 910 の通りだけ、次に 455、227.5 と細かく読み、最後に寸法で間崩れを確定する
   - 寸法は必ず建物の最外周まで振ってある（寸法の外に外壁はない）
   - ガレージ・ポーチ・バルコニーは室外。外周は必ず閉じる
4. **見分け方のコツを1つ教える**
   見た目が似たものは AI が間違えます。プロの見分け方を1つ教えると直ります。例：引戸は点線が描いてある側が引込み側／窓の記号（16020H など）の読み方／引戸の幅は中方立の位置に壁があるかで決まる。
5. **建具などは種類ごとに実例をいくつも見せる**
   「この種類の共通点を覚えて」と頼むと、AI がパターンを覚えて判断できるようになります。
6. **AI の質問には、画像を見ながら1問ずつ答える**
   AI が「これはどっち？」と画像付きで聞いてきたら、番号で答えるだけで十分です。間違って教えたと気づいたら、すぐ訂正します。
7. **確認画像で「おかしい所」を指摘する**
   AI のチェックで見落とした所（トイレに変な壁がある、玄関が外形の外に出ている など）は、人が見るとすぐ分かります。
8. **決まりごとを先に伝える**
   「手直しした図面は上書きしない」「頼んでいない変更はしない」「AI の使用量の上限」など。最初に言っておくと、AI が守って作業します。

逆に、**図面ごとに違う数値（窓のサイズなど）を「規則」として覚えさせない**こと。本番の図面には書いてあるので、規則にすると他の図面で間違えます。

## 出力は必ずチェックしてください（AI のチェックもおすすめ）
スクリプトは作図と確認画像の出力までで、**できた図面が正しいかのチェックはしません**。作者は開発中、毎回 AI（Claude）に確認画像を見せてチェックさせ、間違いを見つけて直してきました。使う時も次をおすすめします。
- `02_出力\` の確認画像（`*_壁と柱.png`・`*_建具の配置.png`：検出した壁・柱・建具を元の図面に重ねた画像）を、コーディング AI に見せて「入力図とずれている所・おかしい所を探して」と頼む
- 指摘された所や、自分の目で気になった所を、Jw_cad で手直しする
- 手直しした図面を AI に渡して比べさせると、次から同じ間違いをしにくいようにスクリプトを直してくれます

## 前提と限界
- ウォークインホームのプレゼンボードの描き方（壁は灰色の塗り、1px ≒ 12.5mm など）に合わせて作っています。図面の設定（色・線の太さ・縮尺）が違う場合は調整が必要です
- 家具・設備の線を壁と読む、吹抜・階段まわりが未対応など、まだ間違えるところがあります。出力は必ず確認してください
